# Portfólio React

Atividade de Programação para Internet - UMC.

Este projeto é a versão em React do portfólio original em HTML e CSS:
https://github.com/felipeniendicker/portfolio-programacao-internet

## Executar

```bash
npm install
npm run dev
```

## Publicação

Importar este repositório na Vercel, com o framework Vite e comando de build `npm run build`.
